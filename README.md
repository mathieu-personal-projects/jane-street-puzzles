# jane-street-puzzles

My [Jane Street puzzles](https://www.janestreet.com/puzzles/) code answers

## About 

These puzzles are resolved using basic Java

## Usage

I made a helper script in `bin/run.sh` wich helps you run the solvers

Using bash
```bash
$ chmod +700 bin/*

$ ./bin/run.sh -l // this lists all the puzzles I resolved yet

$ ./bin/run.sh -p <puzzle-name>
```
